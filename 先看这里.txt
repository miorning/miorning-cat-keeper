安装包包含插件运行文件及中英说明、隐私和许可证文档，图片采用无损压缩。无需编译或安装依赖。

Chrome / Edge 安装：
完整解压到准备长期保留的目录。
打开 chrome://extensions 或 edge://extensions。
开启开发者模式 → 加载已解压的扩展程序。
选择 extension 文件夹（直接包含 manifest.json）。
刷新普通网页。

更新：覆盖原安装目录，重新加载原扩展并刷新网页，不要先卸载。
本地 HTML：扩展详情开启“允许访问文件网址”。

Alt + Shift + K：收纳 / 释放
Alt + Shift + H：隐藏 / 显示

平时拄拐杖龟速小步走；鼠标靠近先警觉稍加速，再逼近就随机骑车或滚走。桌面警觉 / 逃跑距离约为 480 / 300 像素，窄窗口会自动缩小。快速移入能抓到。

右键猫 / 尾巴只有快捷键设置、收纳 / 释放、隐藏 / 显示三项。底下抓住三秒不点才藏，上面仍一圈后藏。按住尾巴可沿边拖动，向页面内拉可弹出猫，等三秒再活动。单击尾巴不吞吐，五连短点打开 B 站彩蛋；工具栏猫也能打开菜单。

同一浏览器资料跨页面保存收纳、藏尾位置与图标显示偏好；右键设置里勾选“显示”可让特定入口在以后收纳时仍然保留。

中英界面按浏览器语言选择。原插件仍运行并处理自己的快捷键。收纳不限五款，漏识别可在设置中手动点选；iframe / canvas 内部不保证可访问。工具栏图标需自己取消固定，不属于网页收纳范围。
