## 一只猫，收起扩展的悬浮入口

- **仅收纳扩展入口：** 只处理已适配或能确认扩展来源的小型悬浮按钮，逐个吸入、逐个放回。网站自带的头像、消息、客服等控件不作为收纳目标；无法确认来源的入口会跳过。
- **原插件继续工作：** 只临时隐藏入口，原插件仍运行并处理自己的快捷键和功能面板。
- **拄拐慢走，被追才跑：** 平时像老爷爷一样龟速小步走；鼠标靠近先警觉稍加快，再逼近就随机骑电动车或翻滚逃跑。安全后恢复慢步。桌面警觉 / 逃跑距离扩大到约 480 / 300 像素，窄窗口会自动缩小范围。
- **上下贴边：** 吃饱变圆、贴顶漂浮，撞顶压扁并回弹；释放后落地成饼、弹起，再朝屏幕竖个中指。角色和藏起后的尾巴贴住网页内容区边缘。
- **拖尾巴拔猫：** 按住尾巴可沿边移位，向页面内拉可弹性拔出黑猫；松手后三秒再活动。尾巴单击不吞吐，连续五次短点会打开喵咛 B 站主页彩蛋。
- **跨页同步与逐项保留：** 同一浏览器资料保存并同步收纳状态、藏尾和相对位置。设置里勾选某个入口的“显示”，它就会放回，以后收纳也保留。
- **中英双语：** 按浏览器语言显示中文或英文。运行资源全部在本地，不需要账号或联网生成。

## 安装与更新

1. 下载 **[MiorningCatKeeper-v0.3.2-Chrome-Edge.zip](https://github.com/miorning/miorning-cat-keeper/releases/download/v0.3.2/MiorningCatKeeper-v0.3.2-Chrome-Edge.zip)**。校验值见同一发布页的 `SHA256SUMS.txt`。
2. 完整解压到准备长期保留的目录，不要在 ZIP 内直接加载。
3. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`，开启「开发者模式 / 开发人员模式」。
4. 选择「加载已解压的扩展程序 / 加载解压缩的扩展」，加载包内直接包含 `manifest.json` 的 **`extension` 文件夹**。
5. 刷新已打开的普通网页。可固定工具栏黑猫，用它随时唤出菜单。用于本地 HTML 时，在扩展详情开启「允许访问文件网址」。

安装包只包含插件运行文件与中英说明、隐私和许可证文档，图片采用无损压缩。无需编译、安装依赖或常驻服务器。通过 GitHub 分发，**未上架扩展商店**；加载后请保留安装目录。

更新时**不要先卸载**：用新版 `extension` 内文件覆盖原安装目录，在扩展管理页重新加载原扩展，再刷新网页。设置属于当前浏览器资料和扩展 ID；改用新目录或新资料不保证继承。

## 两个快捷键，三个右键选项

| 默认快捷键 | 操作 |
| --- | --- |
| `Alt + Shift + K` | 收纳 / 释放，并同步到同一浏览器资料的其他页面 |
| `Alt + Shift + H` | 隐藏 / 显示黑猫 |

右键猫或尾巴，只有 **快捷键设置、收纳 / 释放图标、隐藏 / 显示黑猫** 三项；后两项显示浏览器实际分配的快捷键。冲突或未分配时，从设置打开浏览器原生快捷键页重新绑定。

快速移入猫身上有三秒抓住并点击的机会，左键点击活动中的猫可收纳 / 释放。底部抓住后三秒不点会藏，上方仍在巡游一圈后藏。打开右键菜单会暂停活动。Tab 聚焦后可用 Enter / 空格操作，Shift + F10 打开菜单。

手动补收：右键 →「快捷键设置」→ 展开「收纳范围与其他设置」→「点选扩展悬浮图标」，再点击扩展的小型悬浮入口；Esc 取消。手动点选也会检查扩展来源，不能用来绕过限制收纳网站自己的控件。规则按网站保存，本地文件按路径保存。旧规则在使用前重新检查，不再符合来源要求的目标会跳过。需要恢复时可用「紧急放回全部图标」，再移除规则。

在设置的图标列表勾选“显示”，可立即放回该入口并在以后收纳时保留；取消后重新参与收纳。停用黑猫会恢复被它隐藏的入口。系统开启「减少动态效果」时关闭持续巡游与追逃；后台标签页暂停逐帧动画。

## 收纳范围

- 整理的是**浏览器扩展注入网页的小型悬浮入口**。地址栏旁的浏览器工具栏图标需手动取消固定，不能由另一扩展搬进猫肚子。
- 通过已知适配规则，或入口本身可确认的扩展资源识别来源。支持范围不限五款，但不能保证覆盖所有扩展；仅有内联图形且没有可确认来源的未知扩展入口会跳过。
- MIORNING 喵咛、PagePin、喵咛文本窗、喵咛选片台、bilibili 好友分组加强版有专门适配，避免误藏共用编辑器或面板；本项目未修改或打包这些扩展。
- 不再只凭尺寸、位置或悬浮样式判断来源。网站自己的头像、消息、客服、导航等控件，以及大型面板和正文按钮，不属于收纳对象。
- 跨域 iframe 内部控件、同一 canvas 自绘的独立图标，以及持续重写可见性的元素不保证识别。
- 扩展商店、浏览器设置页、新标签页及部分内置 PDF / 受保护页面不能注入。
- 每轮最多检查 2200 个候选入口、自动收纳最多 80 个；复杂页面可能漏掉可识别的扩展入口，手动点选仍需满足来源要求。放回位置遵循原插件当前布局。
